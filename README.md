# 📋 Task Manager App

A simple and responsive web application built with Python (Flask) and SQLite to help you manage your daily tasks.

---

## ✨ Features
* Add, update, and delete tasks easily.
* Clean and user-friendly interface using HTML/CSS templates.
* SQLite database for storing data locally.

---

## 🛠️ Tech Stack
* **Backend:** Python, Flask
* **Database:** SQLite
* **Frontend:** HTML, CSS, JavaScript
